# Archaeo Lens

I need to make an application that can have a camera on it, be it Android or iOS or even a laptop.My idea is to use your phone or laptop camera to tell you about plants, animals, and minerals using their scientific names and local names Its data repository should be authentic, like if I want to know about minerals then it should be Geological Survey of India or World Wide which can tell you about geology and minerals, you can see their scientific names by just opening the camera in the application.
